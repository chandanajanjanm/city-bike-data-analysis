
# Citi Bike Data Analysis

## Project Overview

This project analyzes Citi Bike usage patterns and explores the relationship between ride demand and weather conditions in New York City.

## Objectives

- Analyze daily and seasonal ride patterns.
- Compare weekday and weekend usage.
- Study the relationship between weather and ride demand.
- Identify data quality issues.
- Generate insights for future demand forecasting.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Open-Meteo Weather API

## Project Workflow

1. Data Collection
2. Data Cleaning and Feature Engineering
3. Exploratory Data Analysis
4. Weather Data Integration
5. Insights and Documentation

## Key Findings

- Temperature showed a positive relationship with daily ride counts.
- Rainfall and wind speed showed weak relationships with ride counts.
- Ride demand varied between weekdays and weekends.
- Zero-distance trips were identified and documented.

## Future Scope

- Machine learning-based demand forecasting.
- Interactive dashboard development.
- Hourly weather and ride analysis.

## Limitations

- Weather analysis covers January–March 2025.
- Weather data was analyzed at the daily level.
- Correlation does not establish causation.
- Zero-distance trips were retained during analysis.
- The analysis does not include holidays or special events.
